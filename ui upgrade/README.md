# UI upgrade

Work on the redesigned front end (`web/`, Next.js + React + TypeScript + Three.js), on branch `ui/ux-improvements`.

- `SAP Asset Lifecycle Dashboard.png`: the design reference (a concept; its figures are illustrative, not project data).
- `build-N/`: one folder per build, holding that build's screenshots. Builds follow `MD/README.md` (numbers from 1000, git tag `build-N`). Name files `NN-page-state.png`, for example `01-launch-admin-desktop.png`.
- The original UI5 screenshots live in `old ui/` and are never changed or deleted.
